Welcome to my Flask Project

In this project I exlored the GET, POST, PUT and DELETE option in the reation of a web Application. 

These are the steps I followed:
Environment Setup:

I began by setting up my development environment in VS Code, creating a dedicated project folder and initializing a virtual environment to keep all my dependencies organized. Installing Flask through pip ensured that I had the latest version of this lightweight framework to work with.



Creating a Basic Flask App:

Next, I imported flask, jsonify and request. Then I created a simple Flask application by writing a small Python script. This involved initializing the Flask app and defining a basic route that would return a simple message when accessed. Running the app started a local server, allowing me to see my work live in the browser.



Adding Routes and Views:

With the basic app in place, I expanded its functionality by adding more routes. Each route was designed to handle different URLs, enabling the app to serve various pages and content. This step allowed me to create a structure where specific functions were responsible for generating the appropriate responses.



Working with Templates:

To separate the application logic from the presentation, I introduced HTML templates using Jinja2. By placing my HTML files in a designated templates folder, I could dynamically render content. This setup made it easier to manage and update the visual aspects of the application without cluttering the core Python code.



Handling User Input:

Interactive functionality was achieved by handling user input through forms. I utilized Flasks request object to capture data submitted by users. This approach allowed me to process input and deliver personalized responses, making the app more dynamic and responsive to user interactions.



Building REST API Endpoints:

I then extended the apps capabilities by creating REST API endpoints that returned JSON responses. This approach was especially useful for scenarios where data needed to be accessed programmatically. Using Postman, I was able to test these endpoints on my local server, ensuring that they behaved as expected.



Testing and Debugging:

Testing was an ongoing process throughout development. I frequently used Postman to send requests to my API endpoints and verify their outputs. Additionally, debugging in VS Code helped me quickly identify and resolve any issues, ensuring that the app was stable and reliable.



Finalizing the Local Deployment:

After thorough testing and debugging, I polished the application by adding error handling and logging to make the code more robust. With everything running smoothly on my local server, I was satisfied that the project was a solid foundation for further development or integration into larger systems.
