Project Deep Dive

What is Sidekick?

Sidekick is a production-grade AI agent built with LangGraph that demonstrates end-to-end agentic AI orchestration. It's not a toy project — it's a fully-featured assistant that can search the web, browse live websites, write files, execute code, and validate its own responses.

The Problem: Most AI projects stop at prompt-chaining. Real production agents need stateful workflows, conditional tool execution, memory persistence, and automated quality control.

My Role

I engineered the complete system architecture: designed the state graph, built the worker/evaluator feedback loop, integrated six different tool suites (web search, Playwright browser automation, file system, Wikipedia, Python REPL, notifications), and implemented checkpointed memory for multi-turn conversations.

Key Achievement: Built an evaluator-backed agent that loops until success criteria are met — a pattern used in production AI systems at major tech companies.

How It Works

1. User Input

Request Processing

User submits a task with success criteria. The Sidekick graph is invoked as a complete superstep with checkpointed memory.

2. Worker Node

LLM Reasoning

The LLM bound to available tools (search, browser, file writer, code executor, etc.) reasons about the best action to take. Tool decisions are encoded in the response.

3. Tool Routing

Conditional Execution

A conditional edge detects tool_calls in the LLM response. If tools are needed, the ToolNode executes them. Otherwise, control passes to the evaluator.

4. Quality Check

Automated Evaluation

The Evaluator node uses structured outputs to verify whether success criteria were met. If not, it loops back to the Worker with feedback.

5. Memory Save

Persistence & Checkpointing

State snapshots are checkpointed to SQLite. Each conversation turn maintains full context, enabling multi-turn coherence and recovery.

6. Response

Success Delivery

Once success criteria are met or the user provides more input, the agent returns the final response to the user with full conversation history.
